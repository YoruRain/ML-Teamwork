# 《机器学习》课程小组作业仓库

本仓库为2024年春季《机器学习》课程的小组作业项目，展示小组成员在课程学习过程中完成的相关实践内容。仓库内主要包含三类文件：

- **Jupyter Notebook 文件**：小组成员撰写的主要代码，包括数据预处理、模型训练、结果分析等关键步骤
- **HTML 文件**：呈现最终的实验效果和结果展示，便于浏览查阅
- **DOC 文件**：各成员撰写的报告

## 个人工作与贡献：

- 参与数据集的选择与预处理，负责数据清洗与可视化分析
- 负责搭建并优化机器学习模型，包括参数调优与实验结果分析
- 使用Softmax回归、MLP、决策树、随机森林、梯度提升算法进行实现
- 撰写了团队整体的 Jupyter Notebook 代码，详细记录了模型训练的全过程及相关分析
- 协助整理最终实验结果，并将主要成果以 HTML 文件形式进行汇报呈现

---

如需了解详细的实验过程或代码实现，请参考仓库中的 Jupyter Notebook 文件。如需浏览最终成果展示，可查阅对应的 HTML 文件。
